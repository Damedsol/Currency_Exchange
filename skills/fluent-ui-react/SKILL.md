## 🎯 Core Philosophy & Architecture
Fluent UI React Components v9 represents a complete rewrite focused on performance, accessibility (a11y), and **static/compile-time CSS-in-JS** using `griffel`. Its architectural foundations are:
*   **FluentProvider:** Must wrap the root of the tree to inject global CSS variables and theme tokens.
*   **Token-Based Design:** Never use raw hex colors or fixed margins. Semantically styled Fluent UI tokens (`theme.colorNeutralBackground1`, `theme.spacingHorizontalM`, etc.) must be rigorously employed.
*   **CSS-in-JS with Griffel (`makeStyles`):** Generates atomic CSS classes instead of injecting dynamic inline styles, minimizing browser style invalidation.

## ⚡ Quick Start

### 1. Initialization at the Root (`main.tsx` or `App.tsx`)

```tsx
import React from "react";
import ReactDOM from "react-dom/client";
import { FluentProvider, webDarkTheme } from "@fluentui/react-components";
import { App } from "./App";
import "./index.css";

ReactDOM.createRoot(document.getElementById("root")!).render(
	<React.StrictMode>
		<FluentProvider theme={webDarkTheme}>
			<App />
		</FluentProvider>
	</React.StrictMode>
);
```

### 2. Creation of a Basic Styled Component (`Header.tsx`)

```tsx
import React from "react";
import { makeStyles, shorthands, tokens, Title1 } from "@fluentui/react-components";

const useStyles = makeStyles({
	container: {
		display: "flex",
		justifyContent: "space-between",
		alignItems: "center",
		backgroundColor: tokens.colorNeutralBackground2,
		...shorthands.padding(tokens.spacingVerticalL, tokens.spacingHorizontalXL),
		borderBottom: `1px solid ${tokens.colorNeutralStroke1}`,
	},
});

export const Header: React.FC = () => {
	const styles = useStyles();

	return (
		<header className={styles.container}>
			<Title1>Currency Exchange</Title1>
		</header>
	);
};
```

## ⚙️ Standard Pattern (Common Design Patterns)

### 1. Currency Exchange Form using `Field`, `Input`, and `Combobox`
Building structured forms with floating labels and interactive error states is achieved using the `Field` component:

```tsx
import React, { useState } from "react";
import {
	makeStyles,
	tokens,
	Button,
	Field,
	Input,
	Combobox,
	Option,
} from "@fluentui/react-components";
import { ArrowSwapRegular } from "@fluentui/react-icons";

const useStyles = makeStyles({
	form: {
		display: "flex",
		flexDirection: "column",
		gap: tokens.spacingVerticalM,
		maxWidth: "400px",
		width: "100%",
	},
	row: {
		display: "flex",
		gap: tokens.spacingHorizontalM,
		alignItems: "flex-end",
	},
});

export const ExchangeForm: React.FC = () => {
	const styles = useStyles();
	const [amount, setAmount] = useState<string>("");
	const [currency, setCurrency] = useState<string>("USD");

	return (
		<form className={styles.form} onSubmit={(e) => e.preventDefault()}>
			<div className={styles.row}>
				<Field label="Amount to send" validationMessage={amount === "0" ? "Amount must be greater than 0" : undefined}>
					<Input
						type="number"
						value={amount}
						onChange={(_, data) => setAmount(data.value)}
						placeholder="0.00"
					/>
				</Field>

				<Field label="Currency">
					<Combobox
						value={currency}
						onOptionSelect={(_, data) => setCurrency(data.optionValue || "USD")}
					>
						<Option value="USD">US Dollar (USD)</Option>
						<Option value="EUR">Euro (EUR)</Option>
						<Option value="GBP">British Pound (GBP)</Option>
					</Combobox>
				</Field>
			</div>

			<Button appearance="primary" icon={<ArrowSwapRegular />} size="large">
				Convert Currency
			</Button>
		</form>
	);
};
```

## 🚀 Advanced / Edge Cases (Advanced Cases & Performance)

### Case 1: Combining Conditional Styles without breaking Griffel (`mergeClasses`)
Never concatenate class strings generated by `makeStyles`. Griffel provides the `mergeClasses` utility to safely resolve atomic CSS class precedence conflicts:

```tsx
import React from "react";
import { makeStyles, mergeClasses, tokens } from "@fluentui/react-components";

const useStyles = makeStyles({
	base: {
		padding: tokens.spacingHorizontalM,
		borderRadius: tokens.borderRadiusMedium,
		transitionDuration: tokens.durationNormal,
	},
	active: {
		border: `2px solid ${tokens.colorBrandStroke1}`,
		backgroundColor: tokens.colorBrandBackground2,
	},
	inactive: {
		border: `1px solid ${tokens.colorNeutralStroke1}`,
		backgroundColor: tokens.colorNeutralBackground1,
	},
});

interface CardProps {
	isActive: boolean;
	children: React.ReactNode;
}

export const ActiveCard: React.FC<CardProps> = ({ isActive, children }) => {
	const styles = useStyles();
	// mergeClasses atomically analyzes and discards duplicate/conflicting styles
	const cardClass = mergeClasses(
		styles.base,
		isActive ? styles.active : styles.inactive
	);

	return <div className={cardClass}>{children}</div>;
};
```

## 🚫 The Do Not List / Common Mistakes

*   **❌ DO NOT use Tailwind CSS or global classes for spacings:** Mixing Fluent UI v9 with Tailwind utility classes disrupts semantic styling and makes dynamic dark/light theme support difficult.
*   **❌ DO NOT use dynamic inline styles (`style={{ color: dynamicColor }}`):** Griffel compiles CSS at compile time. Inline styles bypass this optimization and force the browser to constantly recalculate layouts.
*   **❌ DO NOT use legacy v8 components (@fluentui/react):** Mixing Fluent UI v8 and v9 drastically increases the javascript bundle size and introduces conflicting visual designs.
*   **❌ DO NOT use deep nested CSS selectors (`.parent > .child`):** Griffel discourages deep nested CSS selectors as they cannot be optimized into individual atomic classes. Generate independent styles for each component instead.
