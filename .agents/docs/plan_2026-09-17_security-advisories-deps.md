## GRILL (vocabulary)

| Term | Meaning here |
|---|---|
| **Advisory** | GHSA/CVE whose affected range contains the *resolved* version in `pnpm-lock.yaml` |
| **Override** | `pnpm-workspace.yaml:overrides` — forces a transitive version (security tool) |
| **Catalog** | `pnpm-workspace.yaml:catalog` — where direct deps are actually pinned (`package.json` uses `catalog:`) |
| **Drift** | lockfile pinned behind the range allowed by the override/catalog |
| **Contract test** | `src/config/*.test.ts` — asserts properties of non-code files (Dockerfile, nginx, dependabot…) |
| **SAFE-ish bump** | same major, no API change → patch/minor |
| **Major** | own cycle, needs explicit approval (AGENTS.md: no unrequested scope) |

⚠️ inconsistency noted: analysis/plan live in `.agents/docs/`, the change spec has historically been `.agents/docs/specs/` while the harness prompt says `.agents/specs/`. This plan uses `.agents/docs/specs/change_spec.yaml` (project convention) and states it in the handoff.

## PROPOSE

**Intent.** Give the project *reproducible* SCA evidence, remove the risks the analysis found without touching code, then refresh dependencies in an approved, testable order.

**In scope.** (a) authoritative `pnpm audit`/`pnpm outdated` evidence; (b) override hygiene (bounded majors, no stale exact pins); (c) Dependabot rule scope; (d) same-major direct-dependency refresh via catalogs; (e) CI job that runs audit + tests on PRs (infra → approval); (f) `.deepsec/` decision.

**Out of scope (YAGNI / own cycles).** vitest 5, TypeScript 7, jsdom 30, `@testing-library/jest-dom` 7, lint-staged 17, commitlint 21, `@types/node` 26, pnpm 12; jsdom/undici major migration; any change to `src/services/*` (last cycle is green: 334 tests).

**Approach.** Contract-test-first (TDD) on the *config* files, because the risky changes are config/version policy, not business logic. Never bump a version without re-running the audit gate in the same cycle.

## SPEC

Change spec: `.agents/docs/specs/change_spec.yaml` (`status: active`).

- **R1 — SCA evidence is produced and durably recorded before any dependency change.** `pnpm audit --audit-level=low` + `pnpm outdated` run in the auditing gate, output recorded in `.agents/docs/security_report.md`; `pnpm audit` must end at **0 advisories** before and after the cycle.
- **R2 — No security override can silently jump a major.** Every `overrides` entry is bounded to the major it was chosen for (`^X.Y.Z` or `>=X.Y.Z <X+1.0.0`), except entries explicitly documented as intentional pins.
- **R3 — Security overrides are not stale.** Refresh to the newest patch of the same line: `undici ^7.29.1`, `fast-uri >=4.1.5`, `postcss >=8.5.28`, `nanoid ^3.3.19`, `picomatch ^4.0.7`, `yaml ^2.9.1`, `js-yaml ^4.3.2` (4.x legacy line, keeps `@commitlint` API compatible) — or a documented reason for each value that differs.
- **R4 — Direct dependencies are refreshed inside their current major** from the catalog: `@fluentui/react-components ^9.74.7`, `@fluentui/react-icons ^2.0.341`, `react`/`react-dom ^19.3.0`, `vite ^8.3.0`, `@vitejs/plugin-react ^6.1.1`, `playwright`/`@playwright/test ^1.63.0`, `@biomejs/biome ^2.5.14`, `oxlint ^1.83.0`, `@testing-library/react ^16.3.3`, `@testing-library/user-event ^14.6.7`; majors listed under *Out of scope* stay untouched.
- **R5 — Dependabot rules are minimal and documented.** Every `ignore` entry states the incompatibility that justifies it; `groups` collapses patch/minor updates; the `undici`/`nanoid` rules remain only while jsdom 29 / postcss 8.5 require those lines.
- **R6 — CI validates PRs (infra, needs approval).** `.github/workflows/ci.yml`: Node 24 + pnpm 11, `pnpm install --frozen-lockfile`, `pnpm audit --audit-level=high`, `pnpm typecheck`, `pnpm lint`, `pnpm test`, executed on `pull_request`.
- **R7 — Local tooling does not hold an unaudited dependency tree.** `.deepsec/` is removed from disk (or explicitly audited and documented) and the audit report exists at `.agents/docs/security_report.md`.

**Edge / side cases.** `pnpm-lock.yaml` is regenerated by `pnpm install` (mechanical, excluded from the ≤400-line workload count but reported in `diff --stat`). `engineStrict` + `preferFrozenLockfile: true` ⇒ install must be run with the lockfile opted in; `minimumReleaseAge: 7200` (5 days) will refuse versions published <5 days ago — `undici 7.29.1` is inside the window, so R3 is applied as range change and only installs when the age gate allows it (documented, not forced with `--force`). `hoistPattern: "*"` means an override change rewrites many `node_modules` links → full test run required.

## DESIGN

| Action | File | Why |
|---|---|---|
| modify | `pnpm-workspace.yaml` | R2/R3 overrides + R4 catalog ranges (single source of truth) |

| modify | `.github/dependabot.yml` | R5 groups + documented ignores |
| modify | `src/config/dependabot.test.ts` | R5 contract (existing 8 tests; extend, do not rewrite) |
| new | `.github/workflows/ci.yml` + `src/config/ciWorkflow.test.ts` | R6 (infra → approval) |

| report | `.agents/docs/security_report.md` | R1/R7 — produced by `/audit`, referenced by every future cycle |

Design rules: no new runtime dependency; parser for the YAML contract tests reuses `yaml` (already a transitive dep, but per AGENTS.md "extend and reuse" → parse with a small regex over the `overrides:` block instead of adding a devDependency — zero new deps). No source code under `src/` outside `src/config/*.test.ts`.
